HOW TO USE THIS FILE
====================

***************************************************
** Only suitable for SmartFade ML 3.0.1 or newer **
***************************************************

SmartFade ML has a personality library with 500 of the most common fixtures.
In addition to this there are 100 personality slots that you can fill by
loading personalities from the updated personality library in this ZIP.

A personality loaded in this way will stay in memory until you make a deep
clear or the battery runs out.

Personalities are loaded from the SD card from the Patch menu.

INSTRUCTIONS:

1) Copy the file "PERSLIB.BIN" onto your SD Card.

2) On the console go to:
Menu > Patch > Patch Devices > Load Personalities

3) Select a SLOT number (1-100) to store the personality inside.
- The display shows if the slot is currently EMPTY or the name of the
personality currently stored in that slot.
You will usually select an EMPTY slot.

Press TICK/ENTER to confirm the slot number.

4) Select the MANUFACTURER using the middle wheel.

5) Select the FIXTURE TEMPLATE using the right-hand wheel.

Press TICK/ENTER to confirm

6) To Load more personalities, repeat steps (3) to (5)

7) Finally, press "<<" EXIT to exit back to the start.
