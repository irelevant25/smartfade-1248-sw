overwrite anything in it. Derived artifacts go in `docs/`, `tools/` or `analysis/`
(`analysis/extracted/` is git-ignored because it holds proprietary binaries).

All hashes below were calculated on 2026-09-17 with `sha256sum`. They were not copied
from any other source.

> the product the **ETC SmartFade 1248** (model `SF1248`), and the repository is named
> `smartfade-1248-sw`. These docs use the official name.

## 4. PERSLIB.bin: basic structure (INFERRED, read-only analysis)

Consistency checks all passed on the v11.2.2 file: table contiguity, total fixture count
matching the HTML, and the footprint byte matching the HTML DMX table for FlexAray75-C d1001
(5 channels). The same layout parses the older 7.5.3 `perslib.bin`.

```
0x0000  u16 BE   manufacturer count            (281)
0x0002  char[6]  library version, NUL padded   ("11.2.2")
0x0008  manufacturer table, count × 24 bytes:
          char[18] name (NUL padded, may use all 18 bytes: "AbleliteInternatio")
          u16 BE   fixture count
          u32 BE   offset of this manufacturer's fixture index entries
0x1A60  fixture index, 7 844 × 24 bytes:
          char[18] fixture name
          u8       DMX footprint (1..59 observed)
          u8       unknown (0, 1, 2, 254, 255 most common)
          u32 BE   offset of fixture definition
0x2F9C0 fixture definitions (variable length, e.g. 4-byte records "dmx slot home flags"
          – UNKNOWN beyond the first bytes)
```

No checksum or compression was observed. Decoding stops here on purpose: the SmartFade 1248
has no fixture/personality support, so a PERSLIB parser is not on the roadmap.
