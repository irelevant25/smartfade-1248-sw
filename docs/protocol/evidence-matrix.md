*2026-10-30, SC-1:* the first clearance for sending (poll and listed fetch, read-only session) is recorded in
[safety-checks.md](safety-checks.md); the hypotheses it opens are H66–H68 and the experiment is E8
([reverse-engineering.md](reverse-engineering.md)). The **Capture / HW test** column gains a second host for
those two messages only once E8 has run; nothing in this matrix changes status from the clearance itself.

software, 861 s, the backend's transfer log, **no USBPcap**). It is the **first evidence channel other than SmartSoft** for the
poll / reply / list / fetch protocol (F51–F55, F57) and a second host program on the same PC. The **Capture** cells below carry an
**E8** entry where a feature appeared in that log (JSONL `seq`, no pcap frames); the **HW test** cells carry the owner's untimed
account only. E8 clears nothing: SC-1's poll and listed fetch are still the only messages cleared for sending.
